This countdown is a display, not a permission. Nothing here decides whether a script still works. The service decides that on every read, from the file it actually holds — so editing this page, or letting it sit open for a year, cannot keep an expired script alive. When a script expires its file is deleted from disk, and its loadstring prints Script cannot be loaded, doesnt exist or expired.

A script with no timer still has a ceiling: one year from when it was first published. Re-publishing an existing script does not push that back.
