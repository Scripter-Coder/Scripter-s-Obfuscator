# Scripter's Obfuscator

A modern website for script obfuscation and key management.

## Features

- ✅ Dark theme with animated background
- ✅ User authentication (Sign Up / Log In)
- ✅ Social login (Google / Discord)
- ✅ Plan selection (Basic, Advanced, Pro, God, Custom)
- ✅ User dashboard with stats
- ✅ Custom notification system
- ✅ Date & Time display
- ✅ Responsive design

## Setup

1. Clone this repository
2. Update `js/api.js` with your API URL
3. Configure Google & Discord OAuth in `js/api.js`
4. Deploy to GitHub Pages

## Deployment

1. Push to GitHub
2. Go to Settings > Pages
3. Select branch and save
